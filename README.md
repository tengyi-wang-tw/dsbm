DSBM — Dynamic Symmetric Bottleneck Model

二元對稱瓶頸模型

A structural relationship analysis system.

一套以結構觀察為核心的關係分析系統。


概述


DSBM 並不預測情感，也不進行道德審判。

它更像一個結構觀測系統，用來觀察關係中的失衡、內耗與長期壓力累積。

本模型嘗試將原本難以描述的人際重力與結構摩擦，轉化為可視化的量化沙盒。

核心結構

φ 軸：時間／金錢投入對稱性

A 軸：年齡與人生階段稀釋

F 軸：結構防禦力與承壓能力

Overview

DSBM is a structural relationship analysis system based on binary symmetric game theory.

Rather than predicting emotions or assigning moral judgment, the project focuses on imbalance, contribution asymmetry, and long-term structural friction within interpersonal systems.

Core Axes

φ-axis — contribution symmetry (time / money allocation)

A-axis — age and life-stage dilution

F-axis — defensive capacity and structural resilience

Features


Non-linear penalty correction

Custom parameter studio

Narrative simulation system
